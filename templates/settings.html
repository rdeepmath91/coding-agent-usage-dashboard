Read directly from local coding-agent usage sources. OpenCode is always supported, and Codex CLI becomes active when ~/.codex/state_5.sqlite is present. The dashboard uses read-only connections and does not modify source data.

Environment Variable

OPENCODE_DB_PATH

Source

Built from normalized local session data — model, session timestamps, non-cache input tokens, output tokens, and separate cache read/write metrics where a source exposes them. Total tokens are defined as non-cache input + output assistant-message tokens. Raw provider usage can include cached tokens in input; this dashboard subtracts cache read where needed for source-to-source consistency. Cost is estimated from matched OpenRouter pricing when available.
